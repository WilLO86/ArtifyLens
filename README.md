# 🎨 ArtifyLens – Image Filter App

## 📌 Description

**ArtifyLens** is an interactive image filtering application built with **Streamlit** and **OpenCV**. Users can upload images and apply various visual processing filters in real time, including:

- Edge Detection (Canny)
- Artistic Sketch (custom convolution)
- Random Filter (combination of both)
- Inverted Edge View

---

## ⚙️ Features

- Upload your own images
- Choose between 3 filters via radio buttons
- Optional inversion of edge colors
- Dynamic titles showing applied filters
- Real-time processing with visual spinner
- Side-by-side image comparison (original vs processed)
- Download processed result

---

## 🚀 Technologies Used

- Python
- Streamlit
- OpenCV
- NumPy
- Pillow
- Developed using Windsurf IDE
